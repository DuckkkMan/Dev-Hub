Painel em português para organizar o desenvolvimento do jogo no Roblox Studio.

## Recursos
- Tarefas com categorias, status e prioridade
- Barra de progresso calculada automaticamente
- Rastreador de bugs
- Banco de ideias
- Diário de atualizações
- Busca e filtros
- Exportação e importação de backup JSON
- Layout responsivo para computador, tablet e celular

## Como publicar com GitHub Pages
1. Abra Settings neste repositório.
2. Entre em Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Selecione a branch main e a pasta /(root).
5. Clique em Save e aguarde o deploy.

Depois, o site deverá ficar disponível em:
https://duckkkman.github.io/Dev-Hub/

## Armazenamento
Os dados são salvos no localStorage do navegador. Eles ficam neste navegador/dispositivo e não sincronizam automaticamente com outros dispositivos. Use Exportar backup para guardar uma cópia JSON.

Nenhuma biblioteca ou instalação é necessária: basta abrir o index.html ou usar GitHub Pages.
