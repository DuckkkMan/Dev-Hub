Restaurar backup

Importe um backup criado neste Dev Hub. A importação substitui os dados atuais.

◈

Como os dados são salvos

O Dev Hub usa o armazenamento local deste navegador. GitHub Pages publica o site, mas não sincroniza dados entre dispositivos.

Dica: exporte um backup regularmente e guarde-o em um lugar seguro.
⌫

Apagar dados locais

Remove os dados guardados neste navegador. Esta ação não pode ser desfeita sem um backup.
